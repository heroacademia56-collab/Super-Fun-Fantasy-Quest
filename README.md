## Description
Quest for the Sword of Power is an interactive, text-based adventure game written in Python.  
The player takes on the role of a hero tasked with saving the kingdom from an evil monster by finding the legendary Sword of Power. The game features branching choices, puzzles, random events, and multiple endings to create replayability and fun.

### Repository Contents
- **README.md** — Overview of the project, demo video link, and repository details.
- **proposal.md** — The initial project proposal outlining goals, features, and design considerations.
- **src/project.py** — The main Python program containing the game logic, branching paths, puzzles, and endings.
- **requirements.txt** — Lists any third-party libraries required for the project (currently empty for text-only play, but can be expanded if libraries like `pygame` or `pillow` are added later).

### Design Considerations
The project was designed to be more complex than standard lab assignments by including:
- Multiple branching paths (forest, mountain, cave, ruins, river).
- Interactive puzzles and random dice rolls for unpredictability.
- An inventory system to track items like the Sword of Power.
- Replayability through a loop that allows players to restart without rerunning the program.

### Future Improvements
Potential areas for expansion include:
- Adding more story paths and puzzles for greater depth.
- Implementing a class-based combat system with health, attack, and defense stats.
- Enhancing the narrative with ASCII art or text-based visuals.
- Integrating save/load functionality for longer play sessions.

This project demonstrates creativity, structured design, and interactive storytelling using Python.
